USAGE INSTRUCTIONS
───────────────────────────────────────────────────────────────────────────────

STEP 1: Install Plugin
   WordPress Admin → Plugins → Add New → Upload Plugin
   Choose: wyohoops-game-database.zip
   Click: Install Now → Activate

STEP 2: Import Teams (if not already done)
   WyoHoops DB → Import/Tools
   Click: "Import Default Teams"
   Result: 69 Wyoming schools loaded

STEP 3: Import Basketball Records
   Still on Import/Tools page
   Click: "Import Basketball Records"
   Confirm: Yes, import records
   Result: Games generated from PDF data

STEP 4: View Results
   Admin: Navigate to Teams or Games pages
   Front-end: Add shortcode [wyohoops_gamedb] to any page
   Result: Complete basketball database with rankings
