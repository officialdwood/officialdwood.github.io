### Quick Install Steps
1. Download the `coming-soon-advanced.zip` file
2. Go to WordPress Admin → **Plugins** → **Add New**
3. Click **Upload Plugin** at the top
4. Choose the ZIP file and click **Install Now**
5. Click **Activate Plugin**
6. Find **Coming Soon** in your WordPress admin menu (left sidebar)

## ⚙️ Configuration

After installation, configure your settings:

### 1. Access Settings
- Navigate to **Coming Soon** in the WordPress admin menu

### 2. Configure Options
- **Enable Coming Soon Page**: Toggle the switch to ON
- **Logo Upload**: Click "Choose Logo" to upload your logo (appears centered above text)
- **Background Image**: Click "Choose Background" to upload custom background (optional)
- **Description Text**: Edit or use default text:
  - Default: "Home Of The Most Advanced Basketball Player Database and Player Portal."

### 3. Save & Preview
- Click **Save Changes**
- Click **Preview Coming Soon Page** button to view

## 🔧 How It Works

### When Enabled
- Non-logged-in visitors see the coming soon page
- Administrators can access the site normally
- Preview available via settings button

### When Disabled
- Everyone sees your normal website
- Coming soon page is completely bypassed

## 🎨 Default Design

### Colors
- Background: Matte black (#1a1a1a)
- Text: Golden metallic gradient (#ffd700 to #ffed4e to #ffffff)
- Glow: Multiple golden drop-shadows with varying opacity

### Animations
1. **Description Text**: Subtle shimmer animation (3s cycle)
2. **Coming Soon**: Prominent loading sheen animation (2.5s cycle)
3. **Smoke Overlay**: Gentle floating animation (20s cycle)
4. **Fade-ins**: Smooth entrance animations

### Typography
- Description: 2.5rem, bold (responsive)
- Coming Soon: 3rem, extra bold, uppercase (responsive)

## 📱 Responsive Breakpoints

- **Desktop**: Full size (2.5rem / 3rem text)
- **Tablet** (≤768px): Scaled text (1.8rem / 2rem)
- **Mobile** (≤480px): Compact text (1.4rem / 1.5rem)
