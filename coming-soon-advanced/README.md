# Coming Soon Advanced WordPress Plugin - Version 2.0

## 🎉 Fully Customizable Coming Soon Page!

The **Coming Soon Advanced** plugin now includes comprehensive customization options for colors, sizes, fonts, and more!

## 📸 Preview

![Enhanced Coming Soon Page](https://github.com/user-attachments/assets/30af5509-77d5-4a55-979e-ac06fd0015db)

The coming soon page features:
- **Poppins Italic Bold font** throughout all text
- **Customizable colors** for description, "Coming Soon" text, and button
- **Adjustable text sizes** (12-120px range)
- **Matte black or custom background** with animated smoke overlay
- **"Email Us" button** with customizable colors
- **Animated loading sheen** that adapts to any color
- **Separate logo and background** image uploads
- Fully responsive design

## 📥 Download & Install

### Download Location
**File**: `coming-soon-advanced.zip` (16KB)
**Location**: Root of repository

### Quick Install Steps
1. Download the `coming-soon-advanced.zip` file
2. Go to WordPress Admin → **Plugins** → **Add New**
3. Click **Upload Plugin** at the top
4. Choose the ZIP file and click **Install Now**
5. Click **Activate Plugin**
6. Find **Coming Soon** in your WordPress admin menu (left sidebar)

## ⚙️ Configuration Options

After installation, you have full control over:

### Visual Customization
- **Logo Upload**: Separate from background, displays centered above text
- **Background Image**: Upload custom image (optional)
- **Background Color**: Pick any color when no image is set (color wheel)
- **Description Text**: Customize the main message
- **Description Color**: Choose text color with glowing effect
- **Description Size**: Adjust from 12px to 120px
- **Coming Soon Color**: Choose color (loading animation adapts automatically)
- **Coming Soon Size**: Adjust from 12px to 120px

### Email Button Settings
- **Button Text**: Customize label (e.g., "Email Us", "Contact Us")
- **Email Address**: Set the mailto: destination
- **Button Background Color**: Choose button color from color wheel
- **Button Text Color**: Choose text color on button

### How to Configure
1. Navigate to **Coming Soon** in the WordPress admin menu
2. Toggle **Enable Coming Soon Page** ON
3. Customize all settings to your preference
4. Click **Save Changes**
5. Click **Preview Coming Soon Page** to view
