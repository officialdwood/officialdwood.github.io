Advanced coming soon page with golden metallic text, smoke effects, and customizable settings.

== Description ==

Coming Soon Advanced is a powerful WordPress plugin that creates a stunning coming soon page for your website. It features:

* **Matte black background** with animated smoke overlay effects
* **Golden metallic glowing text** with shimmer effects
* **Animated loading effect** on "Coming Soon..." text with a repeating light sheen
* **Custom logo upload** - Display your logo centered above the description
* **Custom background image** - Upload any image to replace the default matte black background
* **Custom description text** - Easily change the main message
* **Easy on/off toggle** - Enable or disable the coming soon page with a single click
* **Admin access** - Administrators can still access the site normally while the coming soon page is active
* **Fully responsive** - Looks great on all devices

== Installation ==

1. Upload the `coming-soon-advanced` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Coming Soon' in the WordPress admin menu
4. Configure your settings:
   - Toggle the coming soon page on/off
   - Upload a logo (optional)
   - Upload a background image (optional)
   - Customize the description text
5. Save your settings

== Frequently Asked Questions ==

= Can I still access my site when the coming soon page is active? =

Yes! Administrators (users with manage_options capability) can access the site normally. Only non-logged-in visitors will see the coming soon page.

= Can I preview the coming soon page before enabling it? =

Yes! When the coming soon page is enabled, you'll see a "Preview Coming Soon Page" button in the settings that opens the page in a new tab.

= Can I customize the colors? =

The current version features a fixed golden metallic color scheme that matches the design specifications. Future versions may include color customization options.

= What image formats are supported for logo and background? =

The plugin supports all standard image formats: JPG, PNG, GIF, and WebP. PNG is recommended for logos with transparency.
