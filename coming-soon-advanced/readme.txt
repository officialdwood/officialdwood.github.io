== Description ==

Coming Soon Advanced is a powerful WordPress plugin that creates a stunning coming soon page for your website. It features:

* **Fully Customizable Colors** - Choose any color for description text, "Coming Soon" text, button background, and button text
* **Adjustable Text Sizes** - Control the size of description and "Coming Soon" text (12-120px)
* **Poppins Italic Bold Font** - Professional typography throughout
* **Matte black background** with animated smoke overlay effects
* **Customizable glowing text** with shimmer effects
* **Animated loading effect** on "Coming Soon..." text (adapts to any color)
* **Email Us Button** - Add a customizable button with your email address
* **Custom logo upload** - Display your logo centered above the description
* **Custom background image or color** - Upload any image or choose from color wheel
* **Custom description text** - Easily change the main message
* **Easy on/off toggle** - Enable or disable the coming soon page with a single click
* **Admin access** - Administrators can still access the site normally while the coming soon page is active
* **Fully responsive** - Looks great on all devices

== Installation ==

1. Upload the `coming-soon-advanced` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Coming Soon' in the WordPress admin menu
4. Configure your settings:
   - Toggle the coming soon page on/off
   - Upload a logo (optional)
   - Upload a background image or choose a background color
   - Customize the description text, color, and size
   - Customize the "Coming Soon" text color and size
   - Set up the email button with text, email address, and colors
5. Save your settings

== Frequently Asked Questions ==

= Can I customize all the colors? =

Yes! Version 2.0 allows you to customize:
- Background color (when no image is used)
- Description text color
- "Coming Soon" text color
- Button background color
- Button text color

= Can I change the text sizes? =

Yes! You can adjust the size of both the description text and "Coming Soon" text from 12px to 120px.

= Does the loading animation work with any color? =

Yes! The loading sheen animation adapts to whatever color you choose for the "Coming Soon" text.

= Can logo and background images be set separately? =

Yes! In version 2.0, the logo and background image are completely independent. You can upload, change, or remove them separately.

= What font is used? =

All text uses Poppins Italic Bold, loaded from Google Fonts.
