## Color Code Reference

### Common Colors Used
- **Blue variants**: #0047AB (Cobalt), #4169E1 (Royal), #89CFF0 (Columbia), #75AADB (Carolina), #002868 (Navy)
- **Red variants**: #DC143C (Crimson/Red), #C41E3A (Cardinal), #800000 (Maroon)
- **Gold/Yellow**: #FFD700
- **Green variants**: #228B22 (Forest), #2E8B57 (Sea Green)
- **Orange**: #FF8C00, #FFA500
- **Purple**: #8B008B, #5B2C6F
- **Black**: #000000
- **White**: #FFFFFF
- **Silver/Gray**: #C0C0C0
