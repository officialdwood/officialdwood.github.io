# WyoHoops Game Database - Shortcode Information

## The Shortcode

The shortcode for the WyoHoops Game Database app is:

```
[wyohoops_gamedb]
```

## How to Use

1. **Install the Plugin**
   - Upload `wyohoops-game-database.zip` to WordPress
   - Activate the plugin

2. **Add to Any Page or Post**
   - Edit any WordPress page or post
   - Add the shortcode: `[wyohoops_gamedb]`
   - Publish the page

3. **View the Results**
   - The shortcode will display three interactive tabs:
     - **Teams Tab** - Browse, search, and filter teams with rankings
     - **Schedule Tab** - View all games (past and upcoming)
     - **Compare Tab** - Compare two teams head-to-head

## Example Usage

In the WordPress editor, simply add:

```
[wyohoops_gamedb]
```

That's it! The full basketball database interface will appear on that page.

## Features Available via Shortcode

✅ **Teams Tab**
- Search teams by name
- Filter by classification (4A/3A/2A/1A)
- Filter by gender (Boys/Girls)
- Sort by multiple criteria
- View efficiency scores
- Click for detailed team stats

✅ **Schedule Tab**
- View all games
- Filter by status (completed/upcoming)
- Search by team
- Filter by conference/postseason

✅ **Compare Tab**
- Select two teams
- View side-by-side statistics
- See offensive vs defensive matchup analysis
