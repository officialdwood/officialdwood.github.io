## Quick Install Guide

1. **Download** the zip file above (don't unzip it!)
2. Go to **WordPress Admin** → **Plugins** → **Add New**
3. Click **"Upload Plugin"**
4. Choose the zip file you downloaded
5. Click **"Install Now"**
6. Click **"Activate Plugin"**

Done! ✅
