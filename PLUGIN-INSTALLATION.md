# Product Store Plugin - Installation Instructions

## Download & Install

### Step 1: Download the Plugin
Download the **product-store-plugin.zip** file from this repository.

### Step 2: Install in WordPress
1. Log in to your WordPress Admin Dashboard
2. Go to **Plugins** → **Add New**
3. Click the **Upload Plugin** button at the top
4. Click **Choose File** and select `product-store-plugin.zip`
5. Click **Install Now**
6. Once installed, click **Activate Plugin**

### Step 3: Configure Settings
1. Go to **Steel Store** → **Settings** in your WordPress admin menu
2. Enter the email address where you want to receive order notifications
3. Click **Save Settings**

### Step 4: Add Products
1. Go to **Steel Store** → **Add New**
2. Enter your product information:
   - Product Title
   - Product Description
   - Upload an image (click "Upload Image" in the right sidebar)
   - Assign tags (Panels, Trim, Accessories, etc.)
3. Click **Publish**

### Step 5: Display the Store
Add the store to any page using the shortcode:
```
[steel_store]
```

**In Elementor:**
- Add a "Shortcode" widget
- Enter: `[steel_store]`

**In Gutenberg/Block Editor:**
- Add a "Shortcode" block
- Enter: `[steel_store]`

**In Classic Editor:**
- Simply paste: `[steel_store]` into your page content
