# Quick Start Guide - Steel Store Plugin

## 🚀 Get Started in 5 Minutes

### Step 1: Install the Plugin
```bash
# Option A: Download and upload via WordPress Admin
# Go to Plugins > Add New > Upload Plugin

# Option B: If you have FTP access
# Upload wp-steel-store folder to /wp-content/plugins/
```

### Step 2: Activate
1. Go to **WordPress Admin** → **Plugins**
2. Find "Steel Store"
3. Click **Activate**

### Step 3: Configure Email
1. Go to **Steel Store** → **Settings**
2. Enter your email address (where you want to receive orders)
3. Click **Save Settings**

### Step 4: Add Your First Product
1. Go to **Steel Store** → **Add New**
2. Enter product name (e.g., "26 Gauge Metal Panel")
3. Add description in the editor
4. Click **"Upload Image"** on the right sidebar
5. Select/upload a product image (.webp recommended)
6. Check appropriate tags (e.g., "Panels")
7. Click **Publish**

### Step 5: Add More Products
Repeat Step 4 to add all your products. Recommended to add at least 3-5 products for testing.

### Step 6: Display on Your Website

**In Elementor:**
1. Edit any page with Elementor
2. Add a **Shortcode** widget
3. Enter: `[steel_store]`
4. Save and view the page

**In Classic Editor:**
1. Create/edit a page
2. Add: `[steel_store]`
3. Publish the page

**In Gutenberg:**
1. Create/edit a page
2. Add a **Shortcode** block
3. Enter: `[steel_store]`
4. Publish the page

### Step 7: Test It Out!
1. Visit your store page
2. Click category tabs to filter products
3. Add items to cart
4. View cart (click cart button in bottom right)
5. Submit a test order with your email
6. Check your inbox!

## 📋 Default Categories

Your store comes with these pre-configured categories:
- **Panels** (default view)
- **Trim**
- **Accessories**
- **Fasteners**
- **Building Materials**
- **Tools**

You can add more categories at **Steel Store** → **Tags**

## 🎨 What Your Customers See

1. **Category Tabs** at the top to browse by type
2. **Search Bar** to find specific products
3. **Product Grid** with images and titles
4. **Add to Cart** buttons on each product
5. **Fixed Cart Button** in bottom right corner
6. **Cart Modal** to review and manage items
7. **Print Cart** option for offline reference
8. **Submit Order** form with name, email, and notes

## 💡 Pro Tips

### Images
- Use **.webp format** for best performance
- Recommended size: **800x600 pixels**
- Keep file size under **200KB**
- Use consistent style/background for all products

### Organization
- Assign clear, descriptive titles
- Add detailed descriptions
- Use appropriate tags for each product
- Keep similar products together

### Orders
- Check your configured email regularly
- Set up email filters for "Steel Store Order"
- Consider using a dedicated order email
- Respond to customers promptly

## 🔧 Troubleshooting

**Products not showing?**
- Ensure products are Published (not Drafts)
- Check that correct tags are assigned
- Clear your browser cache

**Email not sending?**
- Verify email address in Settings
- Install "WP Mail SMTP" plugin for reliable email
- Check spam folder

**Cart not working?**
- Enable JavaScript in browser
- Clear browser cache and cookies
- Try different browser
