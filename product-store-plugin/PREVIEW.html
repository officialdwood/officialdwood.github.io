🛒 Steel Store - WordPress Plugin

Modern, Minimal Online Store for Steel Products

Quick Start: Install the plugin, add products in WordPress admin, and use the shortcode [steel_store] to display your store on any page or in Elementor.

Key Features

🎨 Modern Design

Sleek, minimal interface with Montserrat font family. Light theme with white, light gray, and dark gray colors. Smooth animations and 3% scale hover effects.

🏷️ Product Management

Easy-to-use WordPress admin interface. Add, edit, remove, and search products. Upload .webp images and assign tags for organization.

📂 Category System

Pre-configured with 6 categories: Panels, Trim, Accessories, Fasteners, Building Materials, and Tools. Add more tags as needed.

🔍 Search & Filter

Customers can search products by name or filter by category tabs. Fast, client-side filtering for instant results.

🛒 Shopping Cart

Add products to cart, adjust quantities, view cart contents, and submit orders. Cart persists using browser localStorage.

📧 Email Orders

Customers submit orders via form. You receive detailed email notifications with product list, quantities, and customer information.

🖨️ Print Support

Print-friendly cart view. Customers can print their cart for offline reference or record keeping.

📱 Responsive

Works perfectly on all devices - desktop, tablet, and mobile. Touch-friendly interface and optimized layouts.

⚡ Elementor Ready

Use the shortcode in any Elementor widget. Also works with Gutenberg, Classic Editor, and any page builder.

💰 No Pricing Required

Built for quotation-based sales. Add pricing later when ready. Perfect for custom steel fabrication projects.

Installation

1. Upload wp-steel-store folder to /wp-content/plugins/
2. Activate the plugin in WordPress
3. Configure email in Steel Store > Settings
4. Add products in Steel Store > Add New
5. Use shortcode [steel_store] on any page

Design Specifications

Font: Montserrat (Semi-Bold 600, Bold 700, Extra Bold 800)
Colors: White (#ffffff), Light Gray (#f3f4f6, #e5e7eb), Medium Gray (#6b7280, #374151), Black (#111827)

  • PHP 7.2 or higher
