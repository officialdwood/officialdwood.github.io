## 🚀 How to Install

### Method 1: Upload via WordPress Admin (Recommended)
1. Download `product-store-plugin.zip` from this repository
2. Go to your WordPress Admin Dashboard
3. Navigate to **Plugins** → **Add New**
4. Click **Upload Plugin** button at the top
5. Click **Choose File** and select `product-store-plugin.zip`
6. Click **Install Now**
7. Click **Activate Plugin**

### Method 2: FTP Upload
1. Download `product-store-plugin.zip`
2. Unzip the file on your computer
3. Upload the `product-store-plugin` folder to `/wp-content/plugins/`
4. Go to WordPress Admin → Plugins
5. Find "Product Store Plugin" and click Activate

## ⚙️ Quick Setup (After Installation)

### Step 1: Configure Email
1. Go to **Steel Store** → **Settings**
2. Enter your email address (for order notifications)
3. Click **Save Settings**

### Step 2: Add Products
1. Go to **Steel Store** → **Add New**
2. Enter product details (title, description, image, tags)
3. Click **Publish**

### Step 3: Display Store
Add this shortcode to any page:
```
[steel_store]
```

## 🆘 Troubleshooting

**Plugin won't install?**
- Ensure you're uploading the .zip file, not the folder
- Check WordPress file upload limits
- Try FTP method if upload fails

**Can't activate plugin?**
- Check PHP version (7.2+ required)
- Check WordPress version (5.0+ required)
- Look for error messages in WordPress

**Products not showing?**
- Ensure products are Published (not Drafts)
- Check that shortcode is correctly placed
- Clear browser cache
